# MVC 3단계 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 리뷰 피드백을 반영한 DTO 기반 사용자 JSON API와 어노테이션 MVC 전환을 구현한다.

**Architecture:** JsonView는 공유 mapper로 모델 Map 전체를 직렬화한다. 앱은 DTO와 예상 가능한 HTTP 오류를 결정하고, mvc는 핸들러 등록·실행·렌더링을 담당한다. 컨트롤러 전환과 레거시 삭제·Dispatcher 이동은 하나의 컴파일 가능한 변경으로 묶는다.

**Tech Stack:** Java 21, Gradle, Servlet 6.1.0, Tomcat 11.0.10, Jackson 2.19.0, JUnit 5, AssertJ, Mockito.

**Spec:** [MVC 3단계 설계안](../specs/2026-10-12-mvc-step3-design.md)
